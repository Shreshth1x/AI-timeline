# The AI timeline

A timeline of the breakthroughs, posts, and cultural moments that shaped AI. Each entry includes a short explanation and links to its sources.

[Explore the timeline](https://aicompletetimeline.vercel.app)

## Run locally

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

## Update the timeline

Entries live in [app/events.json](app/events.json). Include a date, a brief explanation, and reliable source links. Keep entries in chronological order and preserve existing IDs so shared links continue to work.
